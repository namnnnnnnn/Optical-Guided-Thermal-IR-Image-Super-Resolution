# Optical Guided Thermal IR Super Resolution

## Overview
This project performs thermal image super-resolution using an attention-based deep learning model guided by high-resolution optical imagery.

## Tech Stack
- Python
- PyTorch
- NumPy
- OpenCV
- Matplotlib

## Dataset
- Thermal LR images
- Thermal HR images
- Optical guidance images

## Model
AttentionThermalSR

## Metrics
- PSNR
- SSIM
- RMSE
